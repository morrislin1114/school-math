# 國中數學・每日十題

給國三生練計算基本功。每天十題、當天一個單元：基礎 2 題、中等 6 題、進階 2 題。沒有應用題。

範圍從七上的整數與分數，到九上的絕對值。同一天打開是同一組題；按「換一組」才會換題。

## 開啟

```bash
npm start
```

瀏覽器打開 http://127.0.0.1:8731/ 。

數學式用 [KaTeX](https://katex.org/) 從網路載入，第一次打開需要連線。作答紀錄和連續天數存在這台電腦的瀏覽器裡。

## 怎麼練

- 左欄是十五個單元。標「今日」的是這一天排定的單元，連續天數只算這個。
- 其他單元可以複習，不計入連續天數。
- 每題按「核對」，或在答案欄按 Enter（會核對並跳到下一題）。
- 「看詳解」展開步驟。「全部核對」一次看完十題。
- 「列印題目」是空白卷，「列印解答」含答案和步驟。
- 「前一天」「後一天」換日期。後一天不會超過今天。

## 答案怎麼打

| 想寫的 | 輸入 |
| --- | --- |
| 分數 | `-3/4` |
| 根號 | `sqrt(3)` 或 `√3` |
| 次方 | `x^2` |
| 聯立的 x、y | `2, -1` |
| 不等式 | `x ≥ -1/2`，區間寫 `1 ≤ x ≤ 5` |
| 科學記號 | `3.2×10^5` 或 `3.2*10^-4`（係數要滿足 1 ≤ \|a\| < 10） |
| 沒有解 | `無解` |

分數要約到最簡。因式分解要拆完，公因數要提完。一元二次的重根寫一次，開平方要正負兩個解。

`-2^2` 是 `-4`，`(-2)^2` 才是 `4`。

## 單元順序

從 2026-01-01 起，每天換下一個，十五天一輪。

| 年級 | 單元 |
| --- | --- |
| 七上 | 整數與分數的四則運算 |
| 七下 | 比例式、一元一次方程式、一元一次不等式、二元一次聯立方程式 |
| 八上 | 多項式的運算、乘法公式、指數律、科學記號 |
| 八下 | 根式的化簡、根式的四則運算、因式分解、分式的運算、一元二次方程式 |
| 九上 | 絕對值 |

網址可以指定日期和單元，例如 `?date=2026-11-12&unit=linear`。`unit` 用單元代號：`intfrac`、`proportion`、`linear`、`ineq`、`system`、`poly`、`formula`、`exp`、`sci`、`surd`、`surdop`、`factor`、`rational`、`quad`、`abs`。
